# Ant 험지 보행 자체 평가 — 1000회 모델

기본 배포 모델은 `checkpoints/ant_rough_1000.pt`입니다. 저장 iteration 999는 0부터 세므로 이 학습 단계에서 1000회 업데이트를 완료했다는 뜻입니다. 400회 모델의 가중치·Adam 상태·학습률을 복구하고 같은 조건으로 600회 추가 학습했습니다. 더 이전의 사전 학습 이력까지 포함해 처음부터 1000회만 학습한 모델이라는 의미는 아닙니다.

| 항목 | 결과 |

| 원본 Ant 누적 보상 mean ± std | **36.864746 ± 4.010567** |
| 첫 에피소드 | 100/100 |

[100개 에피소드와 보상 항목 원자료](../results/self_evaluation.json). 과제 실행기로 얻은 1000회 모델의 기존 결과와 이번 배포용 실행기의 **100개 개별 return이 전부 일치**합니다. 이는 패키지 검증이며 추가 독립 시험은 아닙니다.

## 평가 설계

400회 모델에서 같은 설정으로 600회 추가 학습한 **Ant Rough Terrain / ant_rough_1000.pt**를 사용했습니다. 이 지도는 이전에도 평가한 지도이므로 이번 1000회 모델에게 완전히 처음 공개된 최종 시험이라고 주장하지 않습니다. `--seed 24 --num_envs 100`으로 각 환경의 첫 에피소드만 측정했습니다. 학습에 쓰던 속도 보상을 제거하고 원본 `classic.ant.ant_env_cfg.RewardsCfg`를 직접 가져와 7개 항목의 함수·가중치를 유지했습니다. 관측·거친 지형·종료 조건까지 원본 평지 Ant와 동일하다는 뜻은 아닙니다.

| 환경 항목 | 고정 조건 |
|---|---|
| 지도 seed | 71 (학습 지도 42와 별도) |
| 지도 크기 | 10×10 m 타일 × 30×24개 |
| 종류 | 평지, 경사, 역경사, 계단, 역계단, 불규칙 블록 |
| 생성 확률 | 종류별 1/6, 치수 단계별 1/3 |
| 경사 비율 | 0.12 / 0.22 / 0.28 (약 6.8° / 12.4° / 15.6°) |
| 계단 높이 / 폭 | 4 / 6.5 / 8 cm, 폭 30 cm |
| 블록 높이 범위 | ±4 / ±6.5 / ±8 cm; 인접 블록 차이는 최대 두 배 |
| 중앙 평탄부 설정 | 2 m |
| 마찰 | 1.0 고정 |
| 초기 배치 | 외곽 2타일 제외, 기본 몸체 높이에 15 cm 추가 |
| 정책 입력 | 382차원, yaw 정렬 높이 스캔 323개 포함 |
| 제어 / 물리 주기 | 60 Hz / 120 Hz |
| 최대 에피소드 | 16초 = 960 step |
| 넘어짐 | 몸통 기울기 90° 초과 |
| 경계 종료 | 지도 끝 2 m 안쪽에서 행정적 종료; 넘어짐과 별도 |

100개 출발 지형은 평지 23, 경사 17, 역경사 15, 계단 17, 역계단 17, 블록 11개였습니다. 무작위 추출이므로 종류별 정확히 같은 개수는 아닙니다. 이동 중 타일을 넘나들기 때문에 출발 지형별 점수를 그 지형만의 성능으로 해석하면 안 됩니다.

이 지도는 알려진 6개 지형 종류에서 **새 배치와 치수 조합**을 평가합니다. 완전히 새로운 종류의 장애물에 대한 일반화를 증명한 것은 아닙니다. 향후 이 지도 결과를 보고 보상을 튜닝하면 이 지도는 개발용이 되므로 최종 평가는 다시 새로운 지도에서 해야 합니다.

## 보상 항목별 평균 누적 기여

| 항목 | 평균 기여 |
|---|---:|
| progress | +27.463116 |
| alive | +7.967083 |
| upright | +1.528317 |
| move_to_target | +7.942057 |
| action_l2 | -0.098038 |
| energy | -4.599823 |
| joint_pos_limits | -3.337966 |

각 항목은 raw reward × weight × dt를 첫 종료 step까지 누적한 값입니다. 7개 항목 합과 실제 return의 개별 에피소드 최대 차이는 `6.71e-7`입니다. `move_to_target`은 방향 정렬 보상이며 도착 보상이 아닙니다. `energy`는 실제 에너지(J)가 아닌 원본 보상 proxy입니다.

## 400회 모델과 비교

| 항목 | 400회 | 1000회 |
|---|---:|---:|
| 누적 보상 mean ± std | 34.618545 ± 3.316981 | 36.864746 ± 4.010567 |
| 전진량 | 27.078 m | 27.463 m |
| 넘어짐 | 1/100 | 0/100 |
| 경계 종료 | 1/100 | 3/100 |
| 평균 정체 비율 | 0.123% | 1.212% |
| 정체 비율 50% 이상 | 0/100 | 2/100 |

평균 점수는 올랐지만 정체는 증가했습니다. 점수 증가 약 2.246 중 약 1.506은 관절 제한 페널티 감소이고, progress 증가는 약 0.384입니다. 따라서 큰 속도 향상이나 모든 지표 개선으로 해석하지 않습니다. 정체는 최근 1초 목표 방향 평균 속도 <0.05 m/s인 비율이며 초기 준비 구간은 제외합니다.

## 과제 발표에 사용할 해석

학습에 쓰지 않은 지도 배치와 치수 조합에서 원본 보상으로 평가했습니다. 단, 반복 확인한 지도이고 단일 학습 seed·16초 시험이므로 광범위한 일반화나 장기 안정성을 증명하지 않습니다. 넘어짐이 없어도 정체가 발생할 수 있습니다. 다른 저장소의 지형·마찰·종료 조건을 유지한 전이 평가는 [별도 보고서](cross_repository_evaluation.md)에 기록합니다.

5분 발표에서는 목표·설계, 통제한 실험 비교, 자체 평가 수치, 실패와 한계를 함께 설명하세요. 독창성 등급과 발표 완성도는 조교의 평가 대상이며 자체 등급을 부여하지 않습니다. 영상은 README의 `--video`로 Ant 0을 사전 지정해 기록할 수 있습니다.
