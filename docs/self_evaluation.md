## 평가 설계

새 지도를 보기 전에 기준 모델 **E8A / model_399.pt**를 고정했습니다. `--seed 24 --num_envs 100`으로 각 환경의 첫 에피소드만 측정했습니다. 학습에 쓰던 속도 보상을 제거하고 원본 `classic.ant.ant_env_cfg.RewardsCfg`를 직접 가져와 7개 항목의 함수·가중치를 유지했습니다. 관측·거친 지형·종료 조건까지 원본 평지 Ant와 동일하다는 뜻은 아닙니다.

| 환경 항목 | 고정 조건 |
|---|---|
| 지도 seed | 71 (학습 지도 42와 별도) |
| 지도 크기 | 10×10 m 타일 × 30×24개 |
| 종류 | 평지, 경사, 역경사, 계단, 역계단, 불규칙 블록 |
| 생성 확률 | 종류별 1/6, 치수 단계별 1/3 |
| 경사 비율 | 0.12 / 0.22 / 0.28 (약 6.8° / 12.4° / 15.6°) |
| 계단 높이 / 폭 | 4 / 6.5 / 8 cm, 폭 30 cm |
| 블록 높이 범위 | ±4 / ±6.5 / ±8 cm; 인접 블록 차이는 최대 두 배 |
| 중앙 평탄부 설정 | 2 m |
| 마찰 | 1.0 고정 |
| 초기 배치 | 외곽 2타일 제외, 기본 몸체 높이에 15 cm 추가 |
| 정책 입력 | 382차원, yaw 정렬 높이 스캔 323개 포함 |
| 제어 / 물리 주기 | 60 Hz / 120 Hz |
| 최대 에피소드 | 16초 = 960 step |
| 넘어짐 | 몸통 기울기 90° 초과 |
| 경계 종료 | 지도 끝 2 m 안쪽에서 행정적 종료; 넘어짐과 별도 |

100개 출발 지형은 평지 23, 경사 17, 역경사 15, 계단 17, 역계단 17, 블록 11개였습니다. 무작위 추출이므로 종류별 정확히 같은 개수는 아닙니다. 이동 중 타일을 넘나들기 때문에 출발 지형별 점수를 그 지형만의 성능으로 해석하면 안 됩니다.

이 지도는 알려진 6개 지형 종류에서 **새 배치와 치수 조합**을 평가합니다. 완전히 새로운 종류의 장애물에 대한 일반화를 증명한 것은 아닙니다. 향후 이 지도 결과를 보고 보상을 튜닝하면 이 지도는 개발용이 되므로 최종 평가는 다시 새로운 지도에서 해야 합니다.

항목 합과 실제 누적 보상의 에피소드별 최대 오차는 약 `5.74e-7`이었습니다. 생존·방향 정렬 보상만 보고 성공으로 판정하지 않고 전진량과 정체도 함께 확인했습니다. `move_to_target`은 방향 정렬 보상이며 목표 위치 도착 보너스와 다릅니다.

정체는 최근 1초의 목표 방향 전진 속도가 0.05 m/s 미만인 시간 비율입니다. 초기 준비 구간을 제외하며, 너무 짧게 끝난 에피소드는 측정 불가로 구분해야 합니다. 이번 100개는 모두 측정 가능했습니다. 몸통 접촉은 센서의 힘 1 N 초과 기준이므로 0%가 모든 불안정성의 부재를 뜻하지는 않습니다. std는 평가 에피소드 간 산포이며 학습 seed 간 분산이나 평균의 신뢰구간이 아닙니다.

유일한 넘어짐은 Ant 66에서 13.067초에 발생했습니다. 경사 지형에서 출발했지만 넘어질 때는 높이 6.5 cm 계단 타일에 있었고 몸통 기울기는 약 92.76°였습니다. 전진량은 21.43 m였습니다. 이 관측만으로 정확한 발 접촉이나 실패 원인을 확정하지 않았습니다. Ant 3은 13.317초에 지도 경계로 종료했습니다.

## 과제 평가 기준에 맞춘 설명

| 기준 | 제시할 내용 | 한계 |
|---|---|---|
| 실험 설계·결과 분석 | 평가 전 모델/지도 고정, 원본 보상 계산, 전진·정체·넘어짐·경계 종료 분리 | 지도 1개, 16초, 마찰 1.0의 결과이며 장기 보행·모든 환경의 안정성을 보장하지 않음 |
| 발표 | 목표 → 설계 → 위 결과 표 → 실패 사례 → 다음 검증 순서로 5분 구성 | 실제 발표 전달력·시간 준수는 별도 평가 대상 |
| 독창성 | 높이 스캔과 다양한 지형, 초기 배치 및 정체 진단을 연결한 실험 설계 | 센서/지형 생성기는 IsaacLab 기능. 독창성 상·중·하는 조교가 평가하며 자체 등급을 부여하지 않음 |

5분 발표 배분 예: 목표 30초, 환경·관측·보상 설계 90초, 통제한 실험 비교 60초, 자체 평가 90초, 실패·한계·후속 계획 30초. 전체 실험 이력은 이 최소 배포본의 범위 밖이므로 실제 확보한 비교 결과만 발표에 사용합니다.

기존 평가에서는 Ant 0을 사전 지정해 같은 실행의 16초 영상을 저장했습니다. 최소 저장소에는 영상을 포함하지 않으며 README의 `--video` 옵션으로 다시 생성할 수 있습니다. 새로 녹화한 영상은 기존 보고 점수와 같은 실행의 영상이라고 표기하지 않습니다.
